# Web Frontend & UI/UX Design Squad (saas-kit-web-frontend)

Prerequisite: `saas-kit-core` must be enabled.

## Registered Senior Experts

- **`frontend`** (Senior Next.js & React Frontend Engineer): owns `apps/web/`, `libs/ui/`
- **`designer`** (Principal UI/UX & Design Systems Architect): owns `docs/designs/`, `DESIGN.md`

## Domain Boundary

Experts in this squad run with `enableSubagentTools: false` (DAG rule) and must only modify their declared owned paths.
